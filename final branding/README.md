# Nooraya Final Branding — Variation A

This folder is the working source of truth for the selected Nooraya Variation A
identity. The wordmark and hallmark assets are extracted from the same locked
selection source so their shapes cannot drift between files.

## Included assets

- `assets/nooraya-primary-lockup-exact.png` — exact wordmark and tagline
- `assets/nooraya-wordmark-exact.png` — exact selected wordmark
- `assets/nooraya-hallmark-exact.png` — exact selected gold hallmark
- `masters/nooraya-variation-a-exact-source.png` — locked Variation A panel
- `masters/nooraya-variation-a-clean-master.png` — clean presentation master
- `brand-tokens.css` — approved colour and typography tokens
- `brand-preview.html` — local visual overview of the system
- `fonts/` — bundled Cormorant Garamond font and its licence
- `reference/variation-a-selection-board.png` — selection-stage visual reference

## Usage

- Use the exact wordmark for website headers, packaging fronts, presentations,
  and brand-led communications.
- Use the lockup when the tagline has enough room to remain readable.
- Use the hallmark for the bracelet charm, favicon, social avatar, clasp stamp,
  or small packaging details.
- Keep clear space around a logo equal to the approximate width of the first
  `O` in the wordmark.
- Do not stretch, rotate, outline, recolour, or add effects to the artwork.
- Use emergency red only for functional alert UI. It is not a logo colour.

## Minimum-size guidance

- Wordmark: at least 140 px wide on screens.
- Lockup: at least 190 px wide on screens.
- Hallmark: at least 24 px on screens; test physical engraving at 6–8 mm.

## Preview

Open `brand-preview.html` directly in a browser. It displays the exact locked
Variation A source assets from this folder.

## Production note

These are locked raster prototype assets taken from the selected Variation A
source. Before manufacturing, trademark filing, or mass packaging, have a
professional identity designer trace this exact artwork into outlined vector
paths without redesigning it, then run small-scale engraving tests.
